# Trails & Tales Backport

Minecraft 1.20's Trails & Tales on 1.12.2: cherry groves, bamboo wood, the sniffer, camels, archaeology, trail ruins, hanging signs, chiseled bookshelves, the calibrated sculk sensor, smithing templates and armor trims, and 1.20.5's armadillo and wolf armor. Every part can be switched off on its own.

## Install

1. Download `TrailsAndTalesBackport-<version>.jar` and `BackportCore-<version>.jar` from [Releases](https://github.com/ExiledRadio/TrailsAndTalesBackport/releases).
2. Put both in your `mods` folder (Forge 1.12.2, 14.23.5.2847 or newer). Client and server both need them.
3. Optional: [Fluidlogged API](https://www.curseforge.com/minecraft/mc-mods/fluidlogged-api) 3.3.3 or newer, for waterlogged blocks.

Back up your worlds before adding it to one you play in.

## Building

Needs Java 8. Put Backport Core's `-dev` jar in `deps/` (named `BackportCore-<core_version>-dev.jar`, see `gradle.properties`), then run `./gradlew build`. The jar is in `build/libs/`.
